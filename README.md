# JDM Pulse 🚗💨  

JDM Pulse est une application dédiée aux passionnés de **Japanese Domestic Market (JDM)**. Elle permet aux utilisateurs de découvrir, liker et partager leurs véhicules JDM préférés, qu'ils possèdent ou qu'ils croisent dans la vraie vie.  

## 📌 Fonctionnalités principales  

👉 **Explorer les JDM** – Parcours une vaste collection de véhicules.  
👉 **Like & Favoris** – Like tes modèles préférés et sauvegarde-les.  
👉 **Ajout de JDM** – Partage ta propre voiture ou celles que tu repères.  
👉 **Classements en temps réel** – Découvre les véhicules les plus appréciés.  
❓ **Communauté** – Interagis avec d'autres passionnés et commente les JDM.

## 🚀 Développement  

### Techno
- Site Web, React.js (pour le front)
- API JDM Pulse, php sous Laravel (pour le back)
